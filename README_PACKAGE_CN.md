# CrackVisionSystem P6.7-performance-ui-hotfix11 完整代码包

本版重点修复与优化：

1. 配置面板新增搜索定位。
   - 顶部增加“搜索配置”输入框。
   - 可按 ONNX、激光、保存目录、帧率、防抖、场景等关键词快速定位页面。
   - 支持 `Ctrl+F` 直接聚焦搜索框。

2. 高频模型状态刷新改为节流合并。
   - 实时检测状态不再逐帧触发整块状态摘要刷新。
   - 默认最小刷新间隔为 120 ms。
   - 可减少长时间运行时的 UI 抖动与主线程负担。

3. 放大预览窗口加入限频更新。
   - 打开放大预览后，不再以主预览同频率持续缩放刷新。
   - 默认限制为 12 FPS，减轻大图缩放带来的额外开销。

4. 保持兼容现有工程。
   - 不改动已有模型路径、推理入口和保存结果格式。
   - 旧版 `system_config.json` 可继续使用，新字段自动使用默认值。

说明：
- 本包为完整源码包。
- 不包含 `models/`，请保留你现有的模型目录。
- 直接覆盖到当前工程同路径即可。
