## P10.0 自动硬件识别与普通相机默认工作区

本包已将六轴位姿、二进制激光测距、普通相机与工业相机图像同步采集整合为独立软件系统。启动后默认进入普通相机 + 实时测量工作区，工业相机模块默认隐藏；需要时可通过“快速切换：双相机”开启。

硬件串口不再按固定 COM 号猜测。系统会自动扫描 COM 口，通过协议帧识别六轴和激光，并自动连接。右侧“位姿激光采集”页提供自动识别、硬件诊断、位姿归零、硬件会话、手动采集和自动采集功能。

主要输出包括：

- `XYZ(m)` 与 `Roll/Pitch/Yaw(°)`；
- 激光距离 `m/mm`；
- 图像文件 `frame_xxxxxx.jpg`；
- 索引文件 `pose_laser_index.csv`。

详细说明见：

- `docs/hardware_pose_laser_integration_cn.md`
- `docs/hardware_serial_debug_cn.md`


## 视距与实际尺寸估计

软件会把激光距离、六轴姿态和当前相机帧尺寸融合，估计视距、姿态修正距离、相机 fx/fy、mm/px 与当前视场覆盖范围，并用于裂缝实际宽度换算。相关结果会在“位姿激光采集”面板实时显示，并写入硬件采集会话的 `pose_laser_index.csv`。
