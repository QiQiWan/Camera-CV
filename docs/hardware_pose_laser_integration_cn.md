# 位姿、激光与图像同步采集说明

本模块面向当前隧道检测仪硬件系统，集成六轴位姿模块、二进制激光测距模块、普通相机与工业相机图像同步保存。系统不再做无关设备的泛化适配，运行时会自动识别六轴和激光所在 COM 口，并将硬件数据转换为可直接阅读和记录的工程量。

## 1. 数据链路

- 六轴位姿模块
  - 串口波特率：115200。
  - 数据帧：`0x49 ... 0x4D`。
  - 输出量：`X/Y/Z`，单位为 m；`Roll/Pitch/Yaw`，单位为 °。
- 激光测距模块
  - 串口波特率：230400。
  - 数据帧：`0xAA + 195 bytes`。
  - 距离字段：`frame[10]` 与 `frame[11]` 组成毫米值。
  - 输出量：距离，单位为 m 和 mm。
- 图像同步
  - 支持普通相机 B、工业相机 A、实时叠加图作为采集图像源。
  - 默认使用“自动”图像源，优先选择普通相机 B 当前帧。

## 2. 自动识别与连接

软件启动后会自动扫描当前 COM 串口，分别用激光帧和六轴帧进行协议级识别。识别成功后会自动填入串口，并尝试连接六轴和激光。打开普通相机或工业相机时，如果硬件尚未连接，也会再次触发自动识别与连接。

推荐现场流程：

1. 插入六轴和激光 USB/串口线，确认设备供电稳定。
2. 启动软件，等待“自动识别”状态显示结果。
3. 打开普通相机 B。
4. 六轴和激光在线后，点击“位姿归零”。
5. 新建硬件会话。
6. 手动采集或启动自动采集。

## 3. 保存文件

默认保存目录：

```text
data/hardware_sessions/pose_laser_YYYYMMDD_HHMMSS/
```

每次采集保存：

```text
frame_000001.jpg
pose_laser_index.csv
```

CSV 字段包括：

```text
frame_id,timestamp,source,image_file,
pos_x_m,pos_y_m,pos_z_m,
roll_deg,pitch_deg,yaw_deg,
raw_x_m,raw_y_m,raw_z_m,
raw_roll_deg,raw_pitch_deg,raw_yaw_deg,
laser_distance_m,
center_x_m,center_y_m,center_z_m
```

## 4. 诊断说明

右侧设备面板提供“硬件诊断”窗口。诊断窗口会显示：

- 当前所有 COM 串口。
- 系统描述、制造商和硬件 ID。
- 每个端口的激光识别结果。
- 每个端口的六轴识别结果。
- 当前选择与建议。
- 可复制的诊断报告。

若识别失败，优先检查：

- 串口是否被串口助手、厂商软件或旧程序占用。
- 设备管理器中 COM 号是否变化。
- 六轴与激光是否插反。
- 设备供电是否稳定。
- USB 转串口驱动是否正常。

## 视距与实际尺寸估计

新版在六轴和激光读数稳定后，会结合当前相机帧尺寸与相机视场角估计相机几何参数：

- 视距距离：直接采用激光测距的光轴距离，单位为 m；
- 姿态修正距离：根据六轴 Roll/Pitch 估计倾斜后的近似法向距离；
- 相机内参估计：根据图像宽高与 HFOV/VFOV 计算 `fx/fy/cx/cy`；
- 实际尺寸比例：输出 X/Y 方向 `mm/px`、当前视场覆盖范围；
- 裂缝实际宽度：检测结果中的像素宽度会优先使用硬件激光 + 六轴 + 相机参数估算得到的比例换算为 mm。

界面中的水平/垂直 FOV 可根据实际镜头参数修正。若垂直 FOV 不确定，可先保留默认值，再通过标准尺或标定板复核。姿态倾角过大时，估计结果会降低置信度；这表示当前成像存在明显斜视，建议尽量让相机光轴正对待测表面。
