# 现代化界面优化说明

本版本面向现场检测场景重新整理了主界面，目标是减少拥挤感、降低首次使用成本，并让普通相机测量、位姿激光融合和结果保存形成更清晰的操作闭环。

## 1. 启动工作台

- 默认进入普通相机测量工作台。
- 工业相机模块默认隐藏，需要时可通过顶部“普通 / 双相机”快速切换。
- 顶部新增深色标题区，集中展示系统名称、工作模式和运行摘要。

## 2. 工具栏重排

原先横向堆叠的按钮较多，容易在中小屏幕上拥挤。本版本改为两行工具栏：

- 第一行：模型配置、保存目录、日志导出、布局恢复、工作区和设备面板切换。
- 第二行：相机预览方式、运行日志显示、普通/双相机模式和总览/实时/测量视图切换。

## 3. 视频与分析区

- 视频显示区域改为深色圆角面板，更接近现代检测软件的视觉习惯。
- 状态卡片更紧凑，减少顶部信息区占用。
- 普通相机优先模式下，隐藏工业相机采集图像和最终测量结果框，保留普通相机、实时叠加和测量相关区域。

## 4. 控件样式

- 统一按钮、输入框、下拉框、标签页、表格、滑块样式。
- 关键操作按钮使用主色或成功色；普通操作保持白底灰边。
- 快速切换按钮使用胶囊式 chip 样式，当前模式更明显。

## 5. 兼容性说明

本次主要调整界面层和交互布局，未改变普通相机、工业相机、六轴、激光和模型推理的底层协议逻辑。
