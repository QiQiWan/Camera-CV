# 相机稳定性热修复说明

本次修复针对“开启相机运行几分钟后自动关闭/疑似崩溃退出”的问题，重点做了以下处理：

1. 预览帧、实时推理帧改为跨线程安全拷贝，避免 OpenCV/Qt 在不同线程之间共享底层缓冲区导致的随机崩溃。
2. Qt 图像显示改为深拷贝 `QImage`，避免 numpy 临时内存在 UI 刷新时失效。
3. 普通相机 B 增加读帧失败与卡流监测，检测到持续失败后自动释放并重连。
4. 工业相机 A 预览线程增加异常保护，预览帧缓存改为安全拷贝。
5. 增加运行时崩溃日志 `runtime_crash.log`，便于现场定位后续问题。

如果现场仍出现退出：
- 优先检查 `runtime_crash.log`
- 检查是否有其他软件占用会议相机/工业相机
- 检查 USB 供电与线缆接触
- 在 Windows 上优先使用独立供电 USB 扩展坞或更换高质量数据线
