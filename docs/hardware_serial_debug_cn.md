# 硬件串口诊断与排查

本软件已集成自动串口识别，不再依赖固定 COM 号。系统会通过实际协议帧判断哪个串口是六轴，哪个串口是激光。

## 1. 正常连接状态

正常情况下，右侧“位姿激光采集”区域应显示：

```text
六轴：在线，XYZ=... m；RPY=... °
激光：在线，... m / ... mm
自动识别：激光=COMx；六轴=COMy
```

## 2. 常见问题

### 未发现 COM 串口

检查 USB 线、供电、驱动和 Windows 设备管理器。

### 无法打开 COM 串口

该端口可能被其他程序占用。关闭串口助手、厂商上位机或旧程序后重试。

### 有字节输入但无法解析

说明串口能读到数据，但数据帧不符合当前硬件协议。常见原因包括端口选错、设备插反、波特率被修改、供电不稳。

### 六轴和激光被选成同一个 COM

系统会阻止两个线程同时占用同一串口。应重新点击“自动识别并连接”，或在诊断窗口确认端口后手动修正。

## 3. 现场建议

1. 插入设备后先等待 2–5 秒，让 Windows 完成 COM 枚举。
2. 点击“自动识别并连接”。
3. 若失败，打开“硬件诊断”并复制报告。
4. 确认激光距离和六轴姿态都在持续刷新后再开始采集。
