# 窗口拖动/缩放抖动修复说明

## 问题现象

在实时预览或资源监测刷新过程中拖动主窗口，窗口位置、尺寸或内部布局可能出现闪动、跳变。

## 主要原因

1. 实时视频 QLabel 在频繁 setPixmap 后，Qt 可能使用当前 pixmap 尺寸更新 sizeHint，进而触发布局重新计算。
2. resizeEvent/moveEvent 过程中仍在刷新状态卡、视频画面和资源表格，容易和操作系统原生窗口拖拽形成抢占。
3. 资源占用表每次采样都执行 resizeColumnsToContents，可能造成表格宽度变化并传导到整体布局。

## 修复内容

1. 新增 StableVideoLabel，固定视频显示控件的 sizeHint，避免视频帧尺寸影响主窗口布局。
2. 主窗口 moveEvent/resizeEvent 增加交互保护时间窗，拖动或缩放时暂缓视频重绘和状态卡重排。
3. 状态卡布局更新改为拖动/缩放结束后延迟执行，避免窗口拖动过程中反复改变容器高度。
4. 资源占用表只在首次刷新时自适应列宽，后续刷新只更新数据，不再反复改变表格布局。
5. 保持原有实时检测、相机预览、资源日志导出等功能不变。

## 验证建议

1. 启动软件，打开普通相机 B 或工业相机 A 预览。
2. 在实时预览刷新期间拖动主窗口，观察窗口位置是否保持跟随鼠标，不再出现跳动。
3. 缩放窗口边缘，观察窗口尺寸变化是否平滑。
4. 打开资源占用面板，确认表格数值刷新时窗口不再横向抖动。
5. 切换“总览四宫格 / 实时优先 / 测量优先”，确认布局仍能正常切换。
