# v13 界面紧凑化与相机参数自动读取说明

## 1. 主界面空间优化

本版将顶部深色标题区改为紧凑型状态条，隐藏冗余副标题，并压缩工具栏、状态卡片和配置摘要占用。启动后核心区域优先留给普通相机预览、实时检测叠加、测量结果和右侧设备面板。

主要变化：

- 顶部标题区最大高度约 54 px；
- 工具栏最大高度约 78 px；
- 配置摘要默认隐藏；
- 状态卡片高度压缩；
- 右侧位姿/激光/尺寸估计模块重新整理为更紧凑的分区。

## 2. 相机参数自动读取

相机参数区新增“读取当前相机参数”。软件会优先从当前图像帧和已打开的普通相机句柄读取：

- 当前图像分辨率；
- FPS；
- 编码 FourCC；
- 曝光；
- 焦点；
- 变焦；
- 亮度、对比度等驱动可提供参数。

需要注意：多数 USB 相机和工业相机驱动不会直接暴露真实镜头视场角，因此软件采用以下顺序估计 HFOV/VFOV：

1. 已有标定比例 `mm_per_pixel` + 当前激光距离反推视场角；
2. 若没有标定比例，则读取当前分辨率，并沿用设备默认/上次保存的水平视场角，同时按宽高比自动修正垂直视场角；
3. 仅在自动估计明显不准时，点击“手动修正”解锁 HFOV/VFOV 输入框。

## 3. 推荐使用流程

1. 打开普通相机 B；
2. 等待系统自动识别六轴和激光；
3. 点击“读取当前相机参数”；
4. 使用钢尺或标定板做一次像素比例标定；
5. 再进行激光 + 六轴 + 图像融合尺寸估计。

这样比手动输入视场角更稳健，也更符合现场设备使用习惯。
