# P6.1 优化说明

本版本针对实时裂缝检测链路做了以下优化：

## 1. 模型加载与复用
- 为 YOLO / ONNX 会话增加路径级缓存，避免重复初始化。
- 当预览模型与分割模型指向同一个 `.pt` 文件时，直接复用同一实例，减少显存/内存占用与切换耗时。

## 2. ONNX 推理链路
- 去掉“先按长边缩放，再放大到固定 ONNX 输入”的双重缩放。
- ONNX 路径直接从原始帧单次缩放到会话输入尺寸。
- 支持优先从 ONNX Session 的真实输入形状读取尺寸，避免配置与模型不一致。

## 3. 工业相机抓拍
- 新增内存直出抓拍：触发后直接从相机缓冲转为 `numpy` 图像。
- 仅在内存抓拍失败时回退到 `temp.jpg` 文件方案。
- 新增抓拍序号，避免拿到旧帧。

## 4. 帧拷贝优化
- 预览帧获取默认返回缓存引用，减少不必要的 `.copy()`。
- UI 帧队列改为轻量传递，降低主线程显示链路中的拷贝次数。

## 5. 宽度测量算法
- 将主测量逻辑从 PCA 轮廓横向跨度，升级为：
  - 最大连通域筛选
  - 距离变换
  - 骨架点半径搜索
  - PCA 兜底
- 对弯曲裂缝、局部分叉裂缝更稳，降低整体横向跨度带来的高估风险。

## 6. 配置默认值
- 默认 `realtime_input_long_side` 调整为 512
- 默认 `realtime_measure_every_n` 调整为 4
- 默认 `max_preview_fps` 调整为 25
- 配置文件改为相对路径，便于迁移部署

## 说明
- 本包未附带模型权重，因此首次运行仍需在界面中选择模型。
- 若你的 ONNX 模型本身固定输入很大，建议后续重新导出更适合实时场景的输入尺寸（如 640 或 960 长边）。
