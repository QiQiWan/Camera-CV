# P6.7 性能与 UI 优化说明

本版本在已有实时裂缝检测优化基础上，继续补了两类现场体验最敏感的问题：
- 实时运行时 UI 主线程状态刷新过于频繁
- 配置项越来越多后，定位某项设置的路径过长

## 1. 模型状态栏节流刷新
- 将高频“实时检测”状态文本改为合并刷新，而不是每一帧都立即更新 QLabel。
- 新增 `ui_status_update_min_interval_ms` 配置，默认 120 ms。
- 实时推理仍会持续进行，但 UI 状态文本、顶部摘要和相关联的配置摘要不再以近似逐帧频率重复重绘。

收益：
- 降低主线程文本布局和多处联动刷新的负担
- 长时间运行时界面更稳，卡顿感更低
- 对 CPU 模式或小屏设备更友好

## 2. 放大预览窗口限频更新
- 当“预览放大”窗口打开时，原先会跟随实时画面高频缩放刷新。
- 新增 `ui_zoom_live_fps` 配置，默认 12 FPS，用于限制放大窗口的实时更新频率。
- 主界面预览仍保持原策略，只有放大窗口改为限频更新。

收益：
- 避免打开大图预览后主界面 FPS 明显掉速
- 降低大分辨率图像在 Qt 缩放链路上的额外 CPU / GPU 压力

## 3. 配置面板增加搜索定位
- 在“模型与检测配置中心”顶部新增搜索框。
- 支持按关键词快速定位配置页面，例如：
  - ONNX / PT / 预览 / 帧率 / 防抖
  - 场景 / 激光 / 串口 / 偏移 / 距离
  - 保存 / 目录 / 导入 / 导出 / 会话
- 支持 `Ctrl+F` 快速聚焦搜索框。
- 搜索后会自动跳转到第一个匹配页面，并在提示区显示当前页面与相关关键词。

收益：
- 配置项变多后仍能快速找到入口
- 现场调参时减少来回翻页成本

## 4. 保持兼容的策略
- 没有改动模型推理接口和结果保存格式。
- 新增配置项都有默认值；旧版 `system_config.json` 继续可用。
- 本轮优化偏向“低侵入、高收益”，适合直接替换现有工程代码。

## 新增配置项
- `ui_status_update_min_interval_ms`: 模型状态摘要最小刷新间隔（毫秒）
- `ui_zoom_live_fps`: 放大预览窗口实时刷新上限
