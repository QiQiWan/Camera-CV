# 资源占用布局优化说明

## 优化目标

资源占用采样表从主窗口纵向布局中移除，避免压缩实时相机预览区和分析结果区的高度。界面保留资源监测能力，但把信息分为两层显示：

1. 底部状态栏显示关键指标：CPU、内存、进程内存、GPU、预览/显示/推理 FPS。
2. 右侧设备栏提供可折叠的“资源占用详情”卡片，展开后显示完整采样表、导出资源日志和验收自检按钮。

## 主要改动

- 主布局不再执行 `main_layout.addWidget(self.resource_usage_group)`。
- `resource_usage_group` 移入右侧滚动区域，默认折叠。
- 新增底部固定高度状态栏 `bottomStatusBar`，高度约 36 px。
- 点击顶部“资源占用”状态卡或底部“资源详情”按钮，会展开右侧资源详情卡片。
- `show_resource_monitor_detail()` 默认展开右侧卡片，不再弹出占屏对话框。
- 资源采样仍按原周期执行，CSV 导出和峰值/均值统计保持不变。

## 验证建议

1. 启动软件后确认相机视频区高度明显增加，资源采样表不再出现在视频区上方。
2. 实时预览开启后观察底部状态栏，CPU、内存、GPU、FPS 应持续刷新。
3. 点击底部“资源详情”或顶部“资源占用”状态卡，右侧栏应展开完整资源表。
4. 点击“导出资源日志”，确认生成 CSV 文件。
5. 在 1366x768、1920x1080、2K 屏幕下分别验证视频区域比例和右侧折叠行为。
